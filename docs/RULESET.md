# 规则集

规则是版本化的数据，放在 `rulesets/`。发布后不再修改；要调整数值就新建 `classic-v2`。每份录像都带规则指纹，规则一变旧录像会明确报错，而不是悄悄算出另一个结果。

```bash
node tournament/cli.js ruleset
```

## classic-v1

竞技基准。排名、基准集和晋级都使用这套规则。

| 规则 | 取值 |
| --- | --- |
| 物理频率 | 固定 60 Hz |
| 地图 | 稀疏格栅，96 像素一格，双人 9×7，人数增加时面积同比增加 |
| 内墙密度 | 0.28，全图连通，低于 0.05 重新生成 |
| 坦克 | 碰撞半径 16，恒速 120 px/s，原地转向 3 rad/s，无加速度和惯性 |
| 操控 | 数字量 -1/0/1，与键盘一致 |
| 反向门 | 反向前静止 8 Tick，转向反向前静止 4 Tick，见 [MOTION.md](MOTION.md) |
| 炮弹 | 半径 3，180 px/s，直线运动，镜面反弹，无反弹次数上限，寿命 10 秒 |
| 同屏炮弹 | 每辆坦克最多 5 发 |
| 开火冷却 | 0.15 秒 |
| 自伤 | 未反弹且出膛 0.25 秒内不伤自己；一旦反弹立即解除 |
| 击杀 | 一发致命 |
| 道具、地雷、激光、护盾 | 关闭 |
| 破墙 | 关闭 |
| 单局时限 | 60 秒，到时存活者平局 |

## party-v1

娱乐模式。物理与 classic-v1 相同，基准地图 7×5，打开四种道具、可破坏内墙，地图风格在稀疏、对称、房间走廊中随机。它不参与经典排名。

## 还原的范围

classic-v1 还原的是玩法机制：迷宫、反弹炮弹、坦克式操控、一发致命、同屏弹数上限。

- 表中数值是本项目的候选值，没有和任何官方版本逐项实测校准。地图尺寸和炮弹寿命尤其应该看作待校准项。校准后用 `classic-v2` 发布。
- 碰撞体是圆形，不是矩形车身。这影响贴墙转向的手感，换成矩形需要新规则集，所有 Bot 的 `tankRadius` 假设也要重新评估。
- 平台不包含、也不打算复制任何现有游戏的美术、音效或关卡数据。所有图形都是程序绘制，地图由种子随机生成。
- 反向门是平台为 AI 竞技加入的规则，键盘玩家在正常操作中感受不到，但它不来自任何原版设计。
